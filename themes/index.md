Le carnet est organisé autour de quatre disciplines — et du cinquième
territoire, celui des ponts, où se tient la plus grande partie du travail.

<section class="tui-section">
    <ul class="tui-liste">
      <li class="tui-ligne-veille">
        <span class="tui-puce" aria-hidden="true">*</span><a class="tui-lien" href="programmation/">Programmation</a><span class="tui-note"> — L'artisanat du code : clarté, lenteur, programmes qui se lisent comme des essais.</span>
      </li>
      <li class="tui-ligne-veille">
        <span class="tui-puce" aria-hidden="true">*</span><a class="tui-lien" href="llm/">LLM</a><span class="tui-note"> — Les modèles de langage, miroirs statistiques du langage humain — et ce qu'ils révèlent.</span>
      </li>
      <li class="tui-ligne-veille">
        <span class="tui-puce" aria-hidden="true">*</span><a class="tui-lien" href="maths/">Mathématiques</a><span class="tui-note"> — Périodes, cycles, symétries : les structures qui émergent d'un regard patient.</span>
      </li>
      <li class="tui-ligne-veille">
        <span class="tui-puce" aria-hidden="true">*</span><a class="tui-lien" href="mythologie/">Mythologie</a><span class="tui-note"> — Les récits donnés aux astres — Eosphoros, Hesperos, et la planète qui les réunit.</span>
      </li>
      <li class="tui-ligne-veille">
        <span class="tui-puce" aria-hidden="true">*</span><a class="tui-lien" href="ponts/">Les ponts</a><span class="tui-note"> — Le territoire du carnet : les passages discrets d'une discipline à l'autre.</span>
      </li>
    </ul>
</section>
